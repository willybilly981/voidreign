VOIDREIGN is an original small-deck deduction card duel in the spirit of XENO-style draw-and-play battlers. Eighteen cards over ten archetypes: an unplayable Sovereign that dooms its bearer when burned, an Usurper whose open execution is the only kill that sticks, blind burns, hand trades, peeks, guards, and a hidden Reborn card that returns a fallen king. Play against the Herald across a first-to-three match.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Everything is static files under game/ - no build step, no network.
